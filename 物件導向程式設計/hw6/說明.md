# 說明文件

## 一、檔案清單

- `input.h` / `input.cpp` - 基底類別，包含輸入和輸入檢測函式。
- `Publication.h` / `Publication.cpp` — 基底類別，包含 `title`、`volume`、`year` 與虛擬的 `input()` / `display()`。
- `Book.h` / `Book.cpp` — `Publication` 的公開繼承，新增 `author`、`ISBN`、`price`。
- `Journal.h` / `Journal.cpp` — `Publication` 的公開繼承，新增 `month`、`ISSN`、`impactFactor`、`annualSubscription`。
- `Magazine.h` / `Magazine.cpp` — `Publication` 的公開繼承，新增 `month`、`editor`、`annualSubscription`。
- `main.cpp` — 示範程式：依序建立三種類別物件並呼叫 `input()` 與 `display()`。

## 二、編譯

請進入 `物件導向程式設計/hw5` 目錄，使用 `g++` 編譯所有來源檔：

```bash
g++ -g -std=c++17 -O2 -finput-charset=BIG5 Input.cpp Publication.cpp Book.cpp Journal.cpp Magazine.cpp main.cpp -o hw6.exe
```

## 三、輸入欄位與範例

程式互動採命令列逐欄輸入，輸入順序與格式如下：

1. Book（書籍）

- title（標題）
- volume（卷號，整數）
- year（年份，整數）
- author（作者）
- ISBN（字串）
- price（價格，浮點數）

2. Journal（期刊）

- title（標題）
- volume（卷號，整數）
- year（年份，整數）
- month（月份，1~12，整數）
- ISSN（字串）
- impactFactor（影響因子，浮點數）
- annualSubscription（年度訂閱費，浮點數）

3. Magazine（雜誌）

- title（標題）
- volume（卷號，整數）
- year（年份，整數）
- month（月份，1~12，整數）
- editor（主編或編輯名稱）
- annualSubscription（年度訂閱費，浮點數）
