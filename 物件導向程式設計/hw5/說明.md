# hw5 使用說明

此專案包含 `Length`（長度）與 `Rectangle`（矩形）兩個類別的簡單示範程式。所有檔案皆使用 Big5 編碼（繁體中文）。

## 編譯：

```
g++ -g -std=c++17 -O2 -finput-charset=BIG5 Length.cpp Rectangle.cpp main.cpp -o hw5.exe
```

## 檔案說明：

- `Length.h` / `Length.cpp`：長度類別（公分+毫米），包含輸入、顯示、加法、乘法（面積）等。

- `Rectangle.h` / `Rectangle.cpp`：矩形類別，使用 `Length` 作為寬與高，提供周長與面積計算。

- `main.cpp`：示範程式。
